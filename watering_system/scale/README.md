# Scale

## Code

The code is written using Platofrm.IO tool. It can not directly be copied to adroino; however, only samll changes are needed for that.

### Calibration

This code calibrates the scale, and lets the user test the calibration. A pre-calculated calibration can also be used.


### Water stop

This code lets the user specify how much water that should be added (in ml) and tells the user when that is achived.
